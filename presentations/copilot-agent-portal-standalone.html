Part one · What an agent is made of

Three parts, one assistant

Every agent you create in Copilot is built from the same three ingredients. Get these right and the rest is clicking buttons.

01 · Purpose

What job does it do?

One clear task for one group of people. Narrow agents give better answers than "help with everything".

"Answer staff questions about leave and travel policy."
02 · Knowledge

What should it read?

SharePoint sites, folders, files or approved websites. The agent answers from these sources and shows where the answer came from.

HR Policies site · Leave-Policy-2026.docx
03 · Instructions

How should it behave?

Tone, format, limits and what to do when it doesn't know. Written in plain sentences, like briefing a new colleague.

"Keep answers under 80 words. Always cite the policy."

Ask the room: "If you had an assistant that only knew one part of your job, which part would you pick?" Take two answers and use one as the running example if it fits.

Part two · How it works

From your files to a cited answer

When someone asks a question, the agent looks through the knowledge you gave it, picks the relevant passages and writes an answer that points back to its source.

1 · Search

Finds the right passage

Only in the sources you added, and only content the person asking is already allowed to open.

2 · Follow the brief

Applies your instructions

Length, tone, format and the "I don't know, ask HR" rule all come from what you wrote.

3 · Answer with a source

Shows its working

Each answer links to the document it used, so people can check it in one click.

Point at the glowing lines in the document. "It doesn't make up the policy. It reads the policy. That's why knowledge is the most important part to get right."

Part four · When to move up

Copilot app or Copilot Studio?

Start in the Copilot app. Move to Copilot Studio when the agent needs to take actions or live outside Copilot.

Agent builder in the Copilot app

Fast, simple, for everyone

  • Built in minutes from a plain-language description
  • Answers from SharePoint, files and approved websites
  • Lives inside Microsoft 365 Copilot and Teams chat
  • Shared with a link, no admin project needed

Best for: Q&A over documents, team helpers, onboarding guides

Copilot Studio

More control, more power

  • Actions through connectors and Power Automate flows
  • Guided conversation topics with branching steps
  • Publish to Teams, a website or other channels
  • Analytics, environments and admin governance

Best for: booking, ticket logging, approvals, customer-facing bots

Keep this short. The message is: you don't need Studio to start. If your app shows a "Copy to Copilot Studio" option on an agent, mention that the agent can grow later without starting over.

Likely questions
Can the agent see my emails or private files?

It uses the knowledge you add to it. People only get answers from content they already have permission to open, so a shared agent doesn't expose files to people who couldn't see them before.

Do I need a special licence?

Creating and sharing agents depends on your organisation's Copilot licences and admin settings. If you don't see Create agent, ask IT whether it's enabled for you.

What if it gives a wrong answer?

Check the cited source first. Usually the document is out of date or the instructions are too loose. Update the file or tighten the instructions and test again.

Can it send emails or book things?

Not from the basic agent builder. Actions like that need Copilot Studio with connectors or flows.

Who can edit the agent after I share it?

You stay the owner. Sharing lets people use it; editing stays with you unless you hand it over.
